# 交通拥堵博弈与纳什均衡求解

《基于拥堵博弈的交通网络建模与纳什均衡求解算法研究》的算法与实验复现仓库。模型采用7节点、10条有向边的自建路网。实验成本为抽象时间单位，数据由代码按固定参数和随机种子生成。

## 复现实验

实验使用 Python 3.13.4，依赖版本见 `requirements.txt`。从仓库根目录运行以下命令。重跑结果写入 `replay_results/`，原始结果在 `results/`。

```bash
python -m pip install -r requirements.txt
python run_v2.py --out replay_results
python verify_v2.py
```

`verify_v2.py`独立核验已保存的基础状态和相图均衡。在相同环境中，可运行 `python verify_v2.py --compare replay_results` 比较结果文件的 SHA-256。图像及环境记录可能随系统和字体而变，可对照两次运行中的数值 JSON 和 CSV。

不需要GPU或外部求解器。图中文字默认使用微软雅黑或黑体，若本机未安装中文字体可修改`run_v2.py`的字体列表。

核心代码：`traffic_game.py`提供基础模型与独立字典偏离验证；`advanced_game.py`提供完整枚举、Dijkstra核对、三种串行最佳响应和三种精确最小费用流；`run_v2.py`定义全部实验；`verify_v2.py`使用另一套标量字典实现检查保存的N12全部1820状态和相图全部均衡。

`results/summary.json`包含可直接核对论文的主要数字。详细结果包括：

- `exact_N12_all_states.json`：N12全部1820个人数向量，包括非均衡状态。

- `algorithm_runs.csv`、`algorithm_summary.csv`：同100初态、3种BR，共300次。
- `scaling_br.csv`、`scaling_summary.csv`、`scaling_flows.json`：N=12、40、80、160、400，每N、每BR规则10次；每个N另运行势流、lex势流和社会流。

## 基础网络与行为假设

节点O、A、B、C、D、E、T，全部司机从O前往T。每条边成本c_e(n)=a_e+b_e n，n包含本人。

|道路|a|b|
|---|---:|---:|
|O→A|2|2|
|O→B|7|1|
|A→C|3|1|
|A→D|12|0|
|B→D|2|2|
|B→E|8|1|
|C→T|14|0|
|C→D|1|0|
|D→T|1|2|
|E→T|3|1|

P1=O→A→C→T；P2=O→A→C→D→T；P3=O→A→D→T；P4=O→B→D→T；P5=O→B→E→T。路径顺序由声明边顺序的DFS遍历固定；拓扑改变后重新枚举，实际列表保存在结果文件。

BR总是先移除当前司机，再计算该司机进入各候选路线的实际成本。仅严格改善时换路；当前路线已为最优时保持不动；多个严格改善候选同为最优时取路径编号最小者。循环BR每轮检查司机0至N−1；随机BR每轮公平洗牌一次；最大收益BR每次重新评估所有司机，选收益最高者，同收益优先司机编号较小者。最大收益算法最后一次全体无收益检查也计入工作量。

工作量分别报告司机oracle查询数和路径候选评估数；后者在本基础网络为前者的5倍。不能只按实际改路次数比较。每个查询都额外以删除本人后的边成本运行Dijkstra，核对与枚举全部路径的最短成本相同。Dijkstra核对属于验证开销，代码未将运行时间作为论文性能结论；两种oracle的相等成本路线可不同。

100初态的种子与旧包一致：seed=0,…,99；`random.Random(20261123+seed)`逐司机均匀选择5条初始路径，三个算法使用同一个初态；随机顺序另用`random.Random(seed)`。规模实验seed=0,…,9，初始化`random.Random(90210+seed)`、随机顺序`random.Random(seed)`。基础全P1轨迹另运行一次。合计451次研究性BR；此外同步反例串行对照1次，基础自检另含2个双路线检验。全部研究BR结果均以独立字典逐司机偏离验证。

## 精确势流与社会最优流

在每条原边e上展开N条容量为1的并行弧。第k弧费用取c_e(k)=a+b k，则使用x条前缀弧的总费用为Rosenthal势a x+b x(x+1)/2。所有边费用序列非降，任何同端点的非前缀选择都可在不增加费用的前提下规范化为前缀，因此聚合最小费用流精确求得全局势极小值。b=0时求解器实际使用后面的等价弧是正常现象，不要求原始解必须呈前缀。

单OD、DAG条件下整数流可分解为N条简单路径，从而得到司机策略。全局势最小解是纯策略纳什均衡，均衡性另用字典法检查。此构造不能未经证明直接推广到多OD共享成本网络或有权司机。

社会目标使用第k增量a+b(2k−1)，前缀和恰为社会成本a x+b x²。

lex势流使用每弧费用B·c_e(k)+a+b(2k−1)，其中B=N(|V|−1)max_e c_e(N)+1。简单路径长度不超过|V|−1，所以B大于任意策略的社会成本；整数势优先最小化，再在所有全局势最小解中选择社会成本最低者。它不保证在所有纯策略均衡中社会成本最小：参数样本9、54、85均给出反例。例如样本9，势极小均衡(Φ,S)=(348,396)，另有势349但社会成本394的均衡。

N12基础：势流返回(2,3,0,2,5)，Φ308、S401；lex势流返回(3,2,0,3,4)，Φ308、S397；社会流返回(5,0,0,3,4)，Φ314、S389、单人最大获益4，因而不是均衡。流目标与完整枚举分别核对，不以流结果反过来定义正确答案。

## 连续机制与相图分类

令μ为C→D基础成本，斜率保持0。以μ=0时的边截距计算α=Aa，H=A diag(b)Aᵀ。人数向量f下的当前路径成本为t=α+Hf，r转q的进入修正为d_rq=H_qq−H_rq。只对有司机的路径r检查t_r≤t_q+d_rq。P2是唯一使用C→D的路线，因此每条约束对μ的系数为−1、0或1，可直接求所有闭区间，无需数值优化器。

N12的7个可行人数区间完整保存在`continuous_NE_intervals.csv`。所有半整数μ=0、0.5、…、12共25点，均将全网成本乘2后用整数完整枚举，核对预测的全部均衡集合一致。删除C→D的均衡成本区间为[390,395]；保留该边的连续参数μ∈[0,3)时全部均衡社会成本均严格高于395；μ=3开始不再具有这一稳健恶化关系。

相图N=2,…,24，μ=0,…,12，299格，每格比较保留与删除C→D的全部均衡社会成本区间，保留是treatment，删除是reference。样本网络实验的方向不同：始终以干预后的网络为treatment、原网络为reference；结果文件已明确标注方向。

记treatment区间[L,U]，reference区间[L0,U0]：

- robust_benefit（稳健改善）：U<L0。
- robust_harm（稳健恶化）：L>U0。
- equal（完全相等）：两个区间均为同一个单点。
- weak_benefit（弱改善）：U=L0且不是同一个单点。
- weak_harm（弱恶化）：L=U0且不是同一个单点。
- overlap（区间重叠）：其余重叠情况，包括两个相同但不是单点的区间。它表示缺少不依赖均衡选择的统一严格方向，不等于“没有影响”。

相图计数只描述这299个预设网格点，不作为随机抽样概率。

## 样本网络的公开生成规则与结果边界

固定原10边拓扑，种子20261124，按声明边顺序独立均匀抽取整数a∈{0,…,15}、b∈{0,…,3}，N=8，共100组。唯一成本退化规则为整网参数全部0时报错中止，不根据实验效果筛选；本次100次均非退化，全部接受。每组基础均衡及社会最优均完整枚举，并用三种流交叉核验。干预：删C→D；新增成本2的B→C；D→T斜率b改为max(0,b−1)，其余不变。当b=0时该“改进”为空操作，仍按规则保留并报告。

随机拓扑种子20261125，固定拓扑次序O,A,B,C,D,E,T；先保留连接全部7节点的前向链，均匀选目标边数8至11，再从其余前向边无放回抽取补足。只接受路径数2至8的候选，不按道路干预效果接受或拒绝。40个接受网络来自41次候选，1个因路径数超8被拒绝。接受后，从删除后仍有O→T通路的边中均匀抽取1条作为删路对象，再按同样a、b范围赋值；N=6。此样本受链骨架、路径数上限、单OD和参数分布限制，不代表所有城市网络。

100参数样本中删C→D没有稳健改善：完全相等65、重叠27、稳健恶化5、弱恶化3；40随机DAG中随机删可删边也没有稳健改善：完全相等25、重叠2、稳健恶化13。原网络的删路改善因此应解释为满足特定需求和路径重叠条件的机制实例，而不是普遍政策建议。新增边或改善斜率的结果同样完整保存，不强求支持某一结论。

## 核验范围

原N4基础自检覆盖625个带标签策略与12500个候选偏离的势恒等式。研究BR每次严格改路均核对ΔΦ=ΔC_i。每个研究oracle查询均核对路径枚举最短成本和Dijkstra最短成本；全部最终策略另用字典计数法逐司机、逐候选路线验证。参数与拓扑实验的690条已保存均衡也逐一独立验证。140个样本的基础网络完整枚举与三种精确流交叉核对势极小值、lex最小二元组、社会最小值。

`verify_v2.py`对N12所有1820状态重新独立计算社会成本、势与均衡身份，并检查相图保存的每条均衡。复跑比较仅针对确定性数据和图像，不比较运行时长。验证范围与样本边界见最终`verification_report.json`和`reproducibility_check.json`，这些检查不等于对任意交通网络的正确性或政策有效性证明。
